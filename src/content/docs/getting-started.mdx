## 一句话结论

**新用户选 KDE 版。** i3wm 版需要自己写配置，作者自己也反复说不建议新手使用。

## 两套方案的区别

| | KDE 魔改版 V5 | i3wm 魔改版 |
| --- | --- | --- |
| 基础系统 | Kali 2026.3 | Kali 2023.3 |
| 桌面环境 | KDE Plasma 6.7.4 | i3wm + polybar |
| 维护状态 | 持续更新（V5，2026 年） | 持续维护（当前基于 Kali 2023.3） |
| 上手难度 | 会基本 Linux 操作即可 | 需要自己写配置、记快捷键 |
| 资源占用 | 完整桌面的正常开销（已按虚拟机优化） | 比 Kali 默认 Xfce4 更省 |
| 下载渠道 | 夸克网盘（V5 地址待公布） | 天翼云盘 |

## 什么时候选 KDE 版

- 想把 Kali 当**日常主力环境**用：要浏览器、输入法、文件管理器、编辑器都现成可用。
- 想要开箱即用的桌面环境：输入法、终端、字体、主题都配好了。
- 想用 V4 起引入的 Gemini CLI，用中文让 AI 帮你生成脚本、拼命令。

## 什么时候可以看 i3wm 版

- 你已经用过 i3 / dwm / sway 这类平铺窗口管理器。
- 你想学 i3 怎么配置 —— 它的 README 里有完整的 polybar 配置和快捷键表，是不错的参考。
- 你不在乎界面是 2023 年的。

但要清楚：**它不是「更轻的 KDE 版」**，而是完全不同的一套操作方式。作者原话是「啥东西都要自己配置」。

## 两种规格怎么选

每个版本都分「完整版」和「系统版」：

- **完整版**：工具已经装好，打开就能用。文件大（V4 压缩包 11.7 GB，解压约 28 GB；V5 的体积作者尚未公布）。
- **系统版**：体积更小的精简版本（V5 压缩包 6.20 GB，解压约 25 GB；V4 是 6.61 GB / 约 22 GB），保留完整桌面与配置。

如果你磁盘空间够，直接下完整版，能省掉后面一堆麻烦。

<Note variant="warn" title="先看一眼能不能装">
镜像只支持 x86-64（amd64），**不支持 ARM**。固件类型是 BIOS，不是 UEFI。
如果你的机器是 ARM 或者只支持 UEFI 启动，这套镜像用不了。
</Note>
