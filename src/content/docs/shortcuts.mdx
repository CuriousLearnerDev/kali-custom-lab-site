## i3wm 版

<Note variant="warn" title="$mod 是 Alt 键">
i3 配置里用 `$mod` 表示修饰键。这个镜像把它映射成了键盘的 **Alt** 键，不是 Win 键。
方向键与 vi 一致：`$mod+j` 左、`$mod+k` 下、`$mod+l` 上、`$mod+；` 右。
</Note>

## 终端里的快捷操作

除了窗口管理，终端本身也有几个高频操作：

| 操作 | 说明 |
| --- | --- |
| `Ctrl + R` | 用 fzf 搜索历史命令 |
| `r` | 打开 ranger 文件管理器 |
| `neofetch` | 查看系统信息 |
