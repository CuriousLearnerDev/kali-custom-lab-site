## 你拿到的不是 ISO

作者发布的是**打包好的 VMware 虚拟机文件**（`.vmdk` / `.vmx`），不是可引导的 ISO 镜像。
这意味着：

> 解压后直接用 VMware 打开，不需要「安装」系统。

也意味着**没法直接装到物理机**。issue #7、#8、#14 都在问物理机安装，作者目前没有提供 ISO。
想在物理机用，只能用官方 Kali ISO 安装，再参照本项目的美化思路自己配。

## 下载

到 <a href="/download/">下载中心</a> 选版本和规格，从网盘下载压缩包。

- V5 系统版 6.20 GB（完整版体积与地址待公布）
- V4 完整版 11.7 GB，系统版 6.61 GB
- i3wm 版 11 GB 以上

<Note variant="warn" title="夸克网盘容量问题">
夸克给新用户的初始容量约 10GB，**存不下 V4 完整版**（11.7 GB）。V5 系统版 6.20 GB 则可以放下。
issue #2、#4、#8 都在反馈这件事。可以先清理网盘空间，或转存到自己的网盘再下载。
</Note>

## 解压：一定要用 7-Zip

这是 issue #15 的成因 —— 用系统自带解压工具解压超大文件容易报错。

- Windows：7-Zip 或 PeaZip
- macOS：Keka
- Linux：`7z x 文件名.7z`

解压完对照一下大小：V5 系统版约 25 GB，V4 完整版约 28 GB，差异太大说明解压不完整。

## 导入 VMware

1. 打开 VMware Workstation / Player。
2. 「打开虚拟机」→ 选择解压目录里的 `.vmx` 文件。
3. 根据宿主机配置调整内存和 CPU。
4. 启动。

### 提示「虚拟机版本不匹配」

issue #1 就是这个报错。建议升级到 **VMware Workstation 17 或更高**。

不过要诚实说明：该 issue 下也有用户反馈升级到 17 之后**仍然**报错，所以这不是一个保证能解决的方案。

### 建议调整的设置

- 内存：宿主机够的话给 4GB 以上
- 开启 3D 图形加速（KDE 桌面需要）
- 磁盘放在 SSD 上（issue #10 讨论终端卡顿时，作者第一个问的就是这个）

## 登录

| 项 | 值 |
| --- | --- |
| 用户名 | `zss` |
| 密码 | `ss` |

<Note variant="danger" title="登录后第一件事：改密码">
这两个值是公开写在 README 里的，任何下载过镜像的人都知道。登录后请立刻执行
`passwd` 修改，并且不要把虚拟机暴露到公网、不要开 SSH 后直接映射端口。
</Note>

<Note variant="info" title="物理机迁移的现实结论">
固件类型是 BIOS。即使你拿到 vmdk 想转成物理机磁盘，也会在引导上遇到麻烦。
目前没有官方支持的物理机路径，别在这上面花太多时间。
</Note>
