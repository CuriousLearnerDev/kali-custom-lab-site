## 1. 修改默认密码

```bash
passwd
```

默认账号 `zss` / 密码 `ss` 是公开信息，改掉是必须的。

## 2. 不要执行整体系统更新

这是全站最重要的一条建议，来自 issue #3（16 条讨论）。

作者的原话：

> 我建议最好如果要用什么工具就更新什么工具就好，系统别更新避免出现系统崩溃的问题

原因是镜像里的美化依赖了大量系统库和插件，整体 `apt upgrade` 会把底层程序换到新版本，
与这些依赖产生冲突。典型症状就是**重启后黑屏，只剩一个鼠标指针**。

具体做法：

```bash
# 需要某个工具时，单独装它
sudo apt install 工具名

# 不要这样做
# sudo apt upgrade
# sudo apt dist-upgrade
# sudo apt autoremove && reboot
```

<Note variant="danger" title="已经黑屏了怎么办">
1. `Ctrl+Alt+F2` 切到 TTY 看看能不能登录；
2. 能登录的话，卸载最近升级的包，或从 `/var/log/apt/history.log` 查这次动了什么；
3. 不能登录就用虚拟机快照回滚 —— 这也是为什么建议**装完就先拍一个快照**。
</Note>

## 3. 装完先拍快照

在 VMware 里做一次快照。出问题时回滚比修快得多。

## 4. 关于用户名

issue #12 问能不能把用户名 `zss` 改掉，作者回复是「不好改的」。

原因不难理解：系统里很多配置、路径、脚本写死了 `/home/zss`。改名会连带出一堆问题。
如果确实需要自己的工作账号，建议**新建一个用户**来用，而不是改默认那个。

```bash
sudo adduser 你的用户名
sudo usermod -aG sudo 你的用户名
```

## 5. 检查输入法与常用服务

V5 把输入法换成了 fcitx5 + 雾凇拼音（rime-ice），解决了 Qt6 程序下无法输入中文的问题。如果换成别的桌面会话后输入法不见了，检查 fcitx5 是否随会话启动。

终端里的常用命令：

- `r` —— 打开 ranger 文件管理器
- `Ctrl+R` —— 用 fzf 搜索命令历史
- `neofetch` —— 看系统信息
