## 更新后重启黑屏，只剩鼠标指针

**这是最常见也最严重的问题**（issue #3，16 条讨论）。

原因：`apt upgrade` 把底层程序升到新版本，与镜像里美化所依赖的库产生冲突。

处理顺序：

1. `Ctrl + Alt + F2` 切到 TTY，看能否登录
2. 能登录：查 `/var/log/apt/history.log`，卸载最近升级的包
3. 不能登录：用 VMware 快照回滚
4. 都没有：重新解压一份镜像

<Note variant="warn" title="根本的预防办法">
不要整体更新系统。需要什么工具就单独装什么工具。
这一条在 <a href="/docs/first-setup/">首次登录后要做的几件事</a> 里也写了。
</Note>

## 终端输入卡顿、按键重复

issue #10（7 条讨论）。作者排查时先问了两件事：

- 宿主机是不是固态硬盘？
- 是**输入**卡，还是**挪动窗口**卡？

可以尝试：

- 把虚拟机磁盘放到 SSD 上
- 给虚拟机分配更多内存
- 开启 3D 图形加速
- 关掉不用的桌面特效

## 解压报错「文件损坏」

见 issue #15。用 **7-Zip / PeaZip / Keka** 重新解压，不要用系统自带解压工具。

解压后核对大小：V5 系统版约 25 GB，V4 完整版约 28 GB。

## VMware 提示虚拟机版本不匹配

issue #1。升级到 VMware Workstation 17+。

注意：该 issue 下也有用户反馈升级后仍报错，所以这不保证能解决。

## 字体太小

issue #11。作者回复「字体大小在设置里面啊」。

系统设置 → 外观 → 字体，调到合适大小；如果整个界面都偏小，改显示缩放比例更有效。

## 工具图标点不开

分两种情况：

- **V5 镜像不再预装第三方工具**：图标点不开是正常的，需要自己从官方源安装。
- **自己装完仍然点不开**：多半是缺 Java 运行时。issue #11 里也有用户反馈过类似情况。

## 无线网卡无法进入监听模式

issue #9 提到了 `airodump-ng` 卡住，但正文没有复现细节，作者也没有回复，
所以没有确切结论。

可以确定的是：**虚拟机的内置无线网卡无法直接进入监听模式**。
需要外置 USB 无线网卡，并在 VMware 里把它直通给虚拟机。

## 不能复制粘贴

如果 VMware Tools 的剪贴板共享失效：

```bash
sudo vmware-user-suid-wrapper
```

## 找不到某条命令

查一下路径有没有进 `PATH`：

```bash
which 命令名
ls /home/zss
```

系统版的工具在 `/home/zss` 下的各个目录里。
